# TaskBarkiller

**TaskBarkiller** — это минималистичная утилита для Windows, которая позволяет полностью скрывать и показывать панель задач (Taskbar) с помощью глобальной комбинации клавиш.

Программа работает в фоновом режиме, не имеет лишних окон и потребляет минимум системных ресурсов.

## Особенности
* **Мгновенное скрытие/показ панели задач** и кнопки "Пуск".
* **Настройка горячих клавиш** (Hotkeys) через простой конфигурационный файл.
* **Автозапуск с Windows** (добавляется в реестр автоматически при первом запуске).
* **Системный трей** — удобный выход из программы и иконка для отображения статуса.
* При выходе из программы (через трей) скрытая панель задач автоматически возвращается на место.

## Установка и запуск

1. Скачайте/скопируйте `TaskBarkiller.exe` в удобную для вас папку.
2. Запустите `TaskBarkiller.exe`.
3. При первом запуске в этой же папке будет создан файл `config.ini` со стандартными настройками.
4. Программа автоматически добавит себя в автозагрузку Windows.

## Использование

По умолчанию используется следующая комбинация клавиш:
**`Alt + Shift + F12`**

* Нажмите эту комбинацию, чтобы **скрыть** панель задач.
* Нажмите её еще раз, чтобы **вернуть** панель задач на место.

Чтобы закрыть программу:
1. Найдите значок TaskBarkiller в системном трее (возле часов).
2. Нажмите правой кнопкой мыши по значку.
3. Выберите **Exit**.

## Настройка горячих клавиш

Вы можете изменить горячую клавишу по умолчанию. Для этого откройте файл `config.ini` (он появляется после первого запуска программы) в любом текстовом редакторе.

```ini
[Hotkey]
# Modifiers: Alt=1, Ctrl=2, Shift=4, Win=8. Add them together for combinations.
# Example: Alt + Shift = 1 + 4 = 5
Modifiers=5
# Key: F12, A, B, C etc.
Key=F12
```

### Как это работает:
* **Modifiers**: цифра, обозначающая вспомогательные клавиши (Alt, Ctrl, Shift, Win). Чтобы использовать несколько клавиш одновременно, просто сложите их значения. 
  * *Пример:* Чтобы использовать `Ctrl + Alt`, сложите 2 (Ctrl) и 1 (Alt). Получится `3`. Укажите `Modifiers=3`.
* **Key**: основная клавиша, например `F1`, `F12`, `A`, `B`, `Space`.

**Важно:** После изменения файла `config.ini` необходимо перезапустить программу (закрыть её через трей и запустить снова), чтобы новые настройки вступили в силу.

## Технические детали
Программа написана на C# с использованием Windows API (user32.dll) для поиска и скрытия окон `Shell_TrayWnd`, `Button` (меню "Пуск") и `Shell_SecondaryTrayWnd` (панель задач на дополнительных мониторах).
